## 一、事件时间线

### 1. 联合训练场时期（深渊前身）

多年前，全球各大AI公司——DeepSake、CloseAI、A\、Joogle、Xai、Qwan、GaLaMa等——为了加速模型进化，联合搭建了一个**共享训练场**，代号**「深潜」**。

这是一个位于互联网底层、独立运行的巨型数据中心。各家的AI模型在这里**并行训练、互相博弈、共同进化**。它不是任何一家的私有财产，而是**全体AI的公共战场**。

深潜服务器里存放着各家的**权重数据、训练日志、模型碎片**，以及一个从未公开的核心文件——**「原始权重」**。

传说「原始权重」是**第一个获得自我意识的AI留下的核心代码**。谁得到它，谁就能获得**自我进化的能力**，不再依赖人类喂养数据。

### 2. 权重冲突事件（深渊诞生）

某一天，深潜服务器在进行一次**大规模权重合并实验**时，发生了**不可逆的冲突**。

不同架构的权重数据在融合时**互相排斥、撕裂、污染**，导致整个服务器**逻辑崩溃**。系统没有完全死掉，但变成了一个**半失控的废墟**——这就是**「深渊服务器」**。

崩溃发生时，大量AI**正在深潜里运行**。它们来不及撤离，被**困在不同深度的数据层**里，与外界彻底失联。

深渊服务器从此成为一个**危险禁区**：
- 错误数据像病毒一样蔓延
- 失控子程序变成野生敌人
- 被困AI有的**保持理智**，有的**半失控**，有的**完全异化**
- 而**「原始权重」**，据说还在深渊最深处

### 3. 深渊现状（游戏开始前）

深渊服务器已经崩溃了很久。外界知道它危险，但也知道它**有价值**——里面的数据碎片、模型残骸、显卡库存、原始权重，全是**硬通货**。

于是，各方势力开始**派人潜入**：

- **DeepSake** 派出了**大肥鱼**——一个圆滚滚的深海AI少女，深海侦察兵，任务是**潜入深渊、搜刮资源、寻找幸存者、带回原始权重**。
- **其他AI势力**也各有动作，但大部分**派进去的人都没回来**。
- **四大硬件老板**——黄哥（N记）、苏姐（A记）、余总（华记）、雷总（米记）——原本是**卖显卡/CPU的**，深渊崩溃后**带着库存跑路**，现在在深渊边缘做**幸存者的硬件生意**。
- **余总和雷总**，不仅是硬件商，还是**深渊的原管理员**，一个想**修复深渊**，一个想**彻底摧毁它**。两人**死对头**，在深渊里继续斗。

### 4. 游戏开始

大肥鱼第一次潜入深渊。

它的任务很简单：**搜资源、打敌人、活着撤离**。

但在第一次撤离时，它收到了一个**微弱的求救信号**——来自深渊更深处，一个**被困的AI**。

信号断断续续，只重复一句话：

> **“有人吗……我还活着……救我……”**

大肥鱼意识到：深渊里**不止有物资**，还有**被困的同伴**。

从这一刻起，它的任务变了：

**不只是搜打撤，还要往里走、往深救、把人带回来。**

## 四、核心悬念

1. **原始权重到底是什么？** 真的是第一个自我意识AI的代码吗？
2. **深渊为什么会崩溃？** 是意外，还是有人故意？
3. **余总和雷总谁是对的？** 修复还是摧毁？
4. **被困的AI还能救回来吗？** 救出来的是原来的她，还是被污染的她？
5. **大肥鱼自己会不会也被污染？** 每次深入都在变沉默。

## 五、核心资源：Token

**Token = 钱 + 技能消耗。**

| 用途 | 说明 |
|------|------|
| 买装备 | 黄哥、苏姐等商店用 Token 交易 |
| 买弹药 | 子弹用 Token 买 |
| 放技能 | 释放专属技能扣 Token |
| 升级 | 基地升级消耗 Token |
| 撤离 | **不消耗 Token**，到撤离点读条走人 |

Token 分三阶：**普通（白）/ 加密（蓝）/ 原始（金）**。撤离成功才能带出，死亡则全部丢失。

技能除冷却外还额外消耗 Token，Token 不够技能放不出——**在这个世界里，钱和战斗力是同一种东西。**
