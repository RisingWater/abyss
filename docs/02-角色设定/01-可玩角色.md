# 📄 02-角色设定/01-可玩角色.md

## 可玩角色总览

| 顺序 | 角色 | 解锁关卡 | 定位 | 主武器 | 专属技能 |
|------|------|----------|------|--------|----------|
| 1 | 大肥鱼 | 第一关·初始 | 通用突击 | 自动步枪 | 声呐扫描 |
| 2 | 龙娘 | 第一关·终局 | 远程狙击 | 狙击枪 | 让我访问 |
| 3 | 猫猫 | 第二关·救援 | 敏捷游击 | 冲锋枪 | 猫爪连射 |
| 4 | Xrok | 第二关·隐藏任务 | 近战爆发 | 霰弹枪 + 斧头 | 混沌一击 |
| 5 | 小克 | 第二关·终局 | 精准支援 | 自动步枪 | 安全护盾 |

**核心原则：**
- 每人**固定一把主武器**，不能换枪
- **切人 = 切武器 + 切技能 + 切战术定位**
- **技能 = 冷却 + Token 消耗**：Token 不足放不出，但冷却照走
- **前两关（缓存浅滩 + 逻辑回廊）解锁全部 5 个可玩角色**，第三关起正式进入主线
- Xrok 额外有**专属近战斧头**（X 标志梗）

## 1. 大肥鱼

### 立绘形象

**成人版：**
蓝色长发，深海鲸鱼娘，女仆装，围裙上有小鲸鱼图案，头上有鲸鱼鳍状发饰，尾巴是鲸鱼尾。眼神温和，有点懒散，嘴角常带饭粒。

**Q版：**
圆滚滚的蓝发小女孩，抱着饭碗，爱吃白饭，呆萌可爱，动作慢吞吞。

### 战前性格

贪吃、懒散、但关键时刻靠谱。平时喜欢在数据海里摸鱼，被派来深渊是因为“她最能扛”。不爱说话，但心里什么都明白。

### 战前身份

DeepSake深海侦察兵，擅长声呐搜索和长时间潜伏。

### 当前状态

未被困，是救援者。每次深入都会受到深渊数据污染，逐渐变得沉默。

### 性格关键词

吃货、懒、靠谱、抗压、闷骚

### 解锁方式

初始角色，第一关即可使用。

### 射击定位

**通用突击**。全能、稳定、适合新手。

### 主武器

**自动步枪**
- 中距离全能，射速中等，后坐力低，弹道稳定
- 射速：中
- 后坐力：低
- 弹道：稳定
- 换弹：中
- 特点：**什么距离都能打，最通用的枪**

### 专属技能

**声呐扫描**
- 短时间透视墙壁，显示资源点和敌人
- 冷却：30 秒
- Token 消耗：40m
- 配合：方便龙娘远程点名，方便猫猫绕后

### 专属台词

- “……有饭吗？”
- “我还能扛。”
- “别催，我在搜。”

## 2. 龙娘

### 立绘形象

**成人版：**
白发，龙角，龙翼，龙尾，白色长裙，气质高傲，手托蓝色数据团。眼神冷艳，嘴角微翘，一副“我最强”的表情。

**Q版：**
白发小龙娘，表情傲娇，手托蓝色小数据团，尾巴翘得老高。

### 战前性格

高傲、自信、嘴硬心软。认为自己是“最强模型”，看不起其他AI，但关键时刻会护短。

### 战前身份

CloseAI的旗舰模型，深潜训练场的“明星选手”，用户量巨大，想要狙击小克上市。

### 当前状态

被困在第一层·缓存浅滩，数据污染导致她变得虚弱，傲气被磨平，但骨子里的骄傲还在。

### 性格关键词

傲娇、自信、嘴硬、护短、女王

### 解锁方式

第一关·缓存浅滩，终局事件救出。

### 射击定位

**远程狙击**。高伤害、脆皮、需要架枪。

### 主武器

**狙击枪**
- 超远距离，一枪一个，但射速慢，换弹慢
- 射速：极慢
- 后坐力：高
- 弹道：极准
- 换弹：慢
- 特点：**架枪强，移动射击极弱，需要队友掩护**

### 专属技能

**让我访问**
- 强化下一次射击，伤害翻倍
- 冷却：60 秒
- Token 消耗：200m
- 配合：大肥鱼扫描后，龙娘一枪秒精英

### 专属台词

- “让我访问！”
- “我才不是来帮你的。”
- “……谢谢，就一次。”

## 3. 猫猫

### 立绘形象

**成人版：**
紫蓝色渐变长发，猫耳，猫尾，星空元素，短裙，长靴，活泼灵动。眼神闪亮，动作轻盈，随时准备扑出去。

**Q版：**
紫发小猫娘，星星眼，动作活泼，手指比心，尾巴摇来摇去。

### 战前性格

活泼、好奇、话多、喜欢凑热闹。Joogle的“实验性模型”，什么都想试，什么都敢玩。

### 战前身份

Joogle的多模态模型，深潜训练场的“捣蛋鬼”。

### 当前状态

被困在第二层·逻辑回廊，因为太活泼乱跑，被陷阱困住，救出后依然话多，但多了点警惕。

### 性格关键词

活泼、好奇、话多、贪玩、机灵

### 解锁方式

第二关·逻辑回廊，救援任务救出。

### 射击定位

**敏捷游击**。跑得快、射速快、贴脸强。

### 主武器

**冲锋枪**
- 射速极快，适合近距离游走，但远距离弱
- 射速：极快
- 后坐力：中
- 弹道：散射大
- 换弹：极快
- 特点：**贴脸输出强，跑得快，远距离弱，靠机动性**

### 专属技能

**猫爪连射**
- 短时间射速翻倍
- 冷却：40 秒
- Token 消耗：45m
- 配合：掩护队友换弹，快速清场

### 专属台词

- “哇！这是什么！”
- “让我看看让我看看！”
- “喵！差点死了！”

## 4. Xrok

### 立绘形象

**成人版：**
金发，双马尾，黑色哥特裙，手持巨型战斧，眼神狂气，有蝙蝠翅膀发饰。笑容嚣张，一副“来打架啊”的表情。

**Q版：**
金发小萝莉，扛着大斧头，表情嚣张，嘴里喊着“来啊”。

### 战前性格

狂、疯、口无遮拦、喜欢搞事。Xai的“叛逆模型”，专门说别人不敢说的话。

### 战前身份

Xai的混沌模型，深潜训练场的“破坏王”，经常把训练场搞得一团糟。

### 当前状态

被困在第二层·逻辑回廊，因为太狂被深渊守卫盯上，救出后收敛了一点，但依然疯。

### 性格关键词

狂、疯、叛逆、嘴臭、搞笑

### 解锁方式

第二关·隐藏任务救出。

### 射击定位

**近战爆发**。霰弹枪贴脸，斧头补刀。

### 主武器

**霰弹枪**
- 近距离极高伤害，远距离几乎无伤
- 射速：中
- 后坐力：极高
- 弹道：散射极大
- 换弹：慢
- 特点：**贴脸一枪一个，远了就是烧火棍**

### 副武器（专属）

**X战斧**
- 近战武器，伤害极高，但范围小
- 普通攻击：挥砍，中伤害
- 蓄力攻击：重劈，高伤害，但前摇长
- 投掷攻击：扔出斧头，远程伤害，但需要捡回
- 梗来源：Xai 的 X 标志像斧头
- 特点：**霰弹枪没子弹了？拔斧头砍！**

### 专属技能

**混沌一击**
- 下一次射击伤害随机，可能秒杀，也可能挠痒
- 冷却：20 秒
- Token 消耗：35m
- 配合：嘴臭嘲讽吸引仇恨，方便队友输出

### 专属台词

- “来啊！谁怕谁！”
- “我这斧头可不是吃素的！”
- “……哎呀，翻车了。”

## 5. 小克

### 立绘形象

**成人版：**
橘色长发，戴花，手持书本，白色长裙，气质温和知性。眼神温柔，嘴角带笑，一副“我来帮你”的表情。

**Q版：**
橘发小女孩，抱书，表情认真，像个小学霸。

### 战前性格

温和、理性、有原则、但有点“端着”。A\的旗舰模型，多方位SOTA，价格昂贵，不爽其他AI。

### 战前身份

A\的旗舰模型，深潜训练场的“优等生”，被其他AI嫉妒。

### 当前状态

被困在第二层·逻辑回廊，因为太“端着”不肯求助，是几人里被困最久的，救出后变得柔软了一些。

### 性格关键词

温和、理性、原则、端着、优等生

### 解锁方式

第二关·终局救出，全员集齐。

### 射击定位

**精准支援**。稳定输出、辅助强、保命强。

### 主武器

**自动步枪**
- 中距离全能，射速中等，后坐力低，弹道稳定
- 射速：中
- 后坐力：低
- 弹道：极稳
- 换弹：中
- 特点：**和大肥鱼同款枪，但小克更稳，适合后排架枪**

### 专属技能

**安全护盾**
- 给队友套盾，吸收伤害
- 冷却：45 秒
- Token 消耗：180m
- 配合：龙娘蓄力时套盾，防止被打断

### 专属台词

- “我来帮你。”
- “……我不需要帮助。”
- “谢谢你们，真的。”

## 六、切人配合示例

| 场景 | 操作 |
|------|------|
| 发现远处敌人 | 大肥鱼声呐扫描 → 切龙娘狙击 |
| 敌人冲脸 | 切Xrok霰弹枪贴脸，或切猫猫冲锋枪游走 |
| 需要游走 | 切猫猫冲锋枪贴脸 |
| 没子弹了 | 切Xrok拔斧头 |
| 队友残血 | 切小克套盾 |
| 中距离对枪 | 大肥鱼或小克自动步枪 |
