## 1. 黄哥（N记）

### 立绘形象

**成人版：**
中年男性，皮衣，墨镜，手持显卡，笑容精明。站在一堆显卡中间，像在开发布会。

**Q版：**
穿皮衣的小胖子，抱着一堆显卡，笑得合不拢嘴。

### 战前性格

精明、会算账、嘴甜心狠、热爱皮衣。N记的老板，深潜训练场的“显卡供应商”。

### 战前身份

N记老板，卖显卡的，深渊崩溃后带着库存跑路，现在做幸存者的显卡生意。

### 当前状态

未被困，是外部NPC，在深渊边缘开店，卖N记显卡、武器、装备。

### 口头禅

“这卡你拿好，矿卡我都不卖你，我卖你的是训练卡。”

### 商店定位

硬件商 + 军火商，卖显卡、武器改装件、装备。

> 角色主武器固定不可更换，商店只卖**改装件与词条**，不卖整枪。

### 商品清单

| 类别 | 商品 | 效果 |
|------|------|------|
| 显卡 | RDX 8090 训练卡 | 武器伤害+30% |
| 显卡 | A4000 矿卡 | 便宜，但10%概率花屏 |
| 显卡 | H4000 企业卡 | 全属性+15%，耗能翻倍 |
| 武器改装 | 枪管校准 | 弹道更稳，射程小幅提升 |
| 武器改装 | 扩容弹匣 | 弹匣容量+25% |
| 武器改装 | 快速换弹 | 换弹速度+30% |
| 装备 | 散热背心 | 减少技能耗能 |
| 装备 | 防尘面罩 | 抗数据风暴 |
| 装备 | 超频腰带 | 移速+20%，持续掉血 |
| 消耗品 | 硅脂 | 临时提升武器性能 |
| 消耗品 | 驱动更新包 | 清除debuff |
| 情报 | 地图情报 | 显示撤离点/资源点 |
| 情报 | 敌人情报 | 显示Boss弱点 |

### 特殊服务

- **显卡租赁**：买不起可以租，撤离成功才扣 Token
- **以旧换新**：旧显卡可以抵扣 Token
- **黑市**：偶尔刷出超规格显卡

### 黄哥的坑

- 10%概率卖你假卡，效果减半
- 心情不好时涨价
- 你帮余总做事，他给你打折；帮雷总，他给你加价

### 支线任务

- **触发：** 在缓存浅滩 C 区找到隐藏入口，或靠近特定箱子
- **场景：** 被困在塌陷的数据舱里，正在煮饺子
- **救援：** 清理周围逻辑炸弹 → 打开数据舱
- **完成：** 豆堡回锚点厨房，提供食物 buff（撤离前食用，本局生效）
