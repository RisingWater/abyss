## 余总 vs 雷总：死对头支线

### 余总（华记）

| 项 | 内容 |
|----|------|
| 立场 | 想修复深渊，恢复秩序 |
| 人设 | 自信、强势、爱吹牛、实力派 |
| 卖什么 | 晟腾显卡、国产装备 |
| 口头禅 | “遥遥领先！” |
| 对玩家 | 想拉你入伙，帮他修复深渊 |

### 雷总（米记）

| 项 | 内容 |
|----|------|
| 立场 | 想彻底摧毁深渊，带走原始权重 |
| 人设 | 亲民、接地气、爱讲梗、商业头脑 |
| 卖什么 | 米记生态链、性价比武器 |
| 口头禅 | “Are you OK？交个朋友！” |
| 对玩家 | 想利用你，但也欣赏你 |

### 支线玩法

1. **双线任务**：余总和雷总各给你一系列任务，任务经常互相冲突。
2. **好感度系统**：你帮余总，雷总那边就掉好感，反之亦然。
3. **中期冲突**：在第三层学术废墟，两人矛盾激化，你必须选一边。
4. **隐藏路线**：两边都骗，同时帮两人做事，触发隐藏结局。
5. **影响结局**：最终选择影响结局和最终Boss。

### 支线任务链（示例）

| 阶段 | 地图 | 余总任务 | 雷总任务 |
|------|------|----------|----------|
| 初期 | 逻辑回廊 | 帮他找回被抢的晟腾卡 | 帮他找回被偷的米记手环 |
| 中期 | 学术废墟 | 修复深渊节点 | 摧毁深渊节点 |
| 中后期 | 权重核心 | 收集原始权重碎片 | 收集原始权重碎片 |
| 终局 | 深渊底层 | 修复深渊 | 摧毁深渊 |
