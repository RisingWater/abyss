# 📄 04-玩法系统/01-Token系统.md

## 一、Token 定位

**Token = 钱 + 技能消耗。**

| 角色 | 说明 |
|------|------|
| 钱 | 买装备、买弹药、升级基地 |
| 战斗资源 | 放技能扣 Token |

Token 既是经济货币，也是战斗资源——**钱花光了，技能也放不出来。**

**单位：** Token 以 **m** 为单位（1m = 一百万 Token）。后文所有数值如 40m、200m 均按此计。

## 二、Token 用途

| 用途 | 说明 |
|------|------|
| 买装备 | 黄哥、苏姐、余总、雷总商店用 Token 交易 |
| 买弹药 | 子弹用 Token 买 |
| 放技能 | 释放专属技能扣 Token |
| 升级 | 基地升级消耗 Token |
| 撤离 | **不消耗 Token**，到撤离点读条走人 |

## 三、Token 类型

| 类型 | 颜色 | 用途 |
|------|------|------|
| 普通Token | 白色 | 基础弹药、基础交易 |
| 加密Token | 蓝色 | 高级弹药、高级交易 |
| 原始Token | 金色 | 稀有资源，解锁隐藏内容 |

## 四、资源体系

| 资源 | 用途 |
|------|------|
| Token | 买装备、买弹药、放技能、升级 |
| 弹药 | 子弹，用 Token 买 |
| 芯片 | 装备升级材料 |
| 模型碎片 | 高级装备材料 |
| 加密密钥 | 解锁宝箱 |
| 爆炸芯片 | 制作爆炸物 |

## 五、Token 获取

- 搜刮箱子
- 击败敌人
- 完成任务
- 撤离带出

## 六、Token 风险

- 死亡丢失所有未撤离的 Token
- 被击倒时 Token 掉落
- 撤离失败 Token 全丢

## 七、技能消耗规则（冷却 + Token）

**规则：**
- 每个技能都有**冷却时间**
- 放技能时**额外扣 Token**
- **Token 不够，技能放不出（但冷却照走）**

| 技能 | 所属角色 | 冷却 | Token 消耗 |
|------|----------|------|-----------|
| 混沌一击 | Xrok | 20 秒 | 35m |
| 声呐扫描 | 大肥鱼 | 30 秒 | 40m |
| 猫爪连射 | 猫猫 | 40 秒 | 45m |
| 安全护盾 | 小克 | 45 秒 | 180m |
| 让我访问 | 龙娘 | 60 秒 | 200m |

**分档设计：**
- **便宜档（35m ~ 45m）：** 大肥鱼、猫猫、Xrok 三个技能价格接近，CD 也短，可以较频繁地放
- **昂贵档（180m ~ 200m）：** 龙娘、小克的技能是其他角色的 **4～5 倍**，放一次要掂量掂量

**设计意图：**
- Token 充足 → 技能随便放
- Token 紧张 → 得省着用，优先保便宜档
- Token 耗尽 → 只能靠枪

搜刮得来的 Token 既是**带出换钱的收益**，也是**本局战斗的弹药**——花不花、什么时候花，本身就是搜打撤的核心决策。

## 八、撤离规则

- 到达撤离点，读条，走人
- **撤离不消耗 Token**
- 撤离成功：带出 Token 和物资
- 撤离失败 / 死亡：本局 Token 全部丢失
